# MyAppMVC - Bài thực hành 02

ASP.NET Core MVC .NET 8 - Controller truyền List<Product> và List<Category> qua ViewBag.

## Chạy project
1. Mở `MyAppMVC.csproj` bằng Visual Studio 2022/2026.
2. Chọn HTTPS hoặc IIS Express.
3. Nhấn `Ctrl + F5`.
4. Trang mặc định mở danh sách sản phẩm.

## URL mẫu
- `/Product`
- `/Product/Category/1`
- `/Product/Detail/1`

Project có sẵn ảnh SVG mẫu trong `wwwroot/images/products`, không cần tải ảnh ngoài.
